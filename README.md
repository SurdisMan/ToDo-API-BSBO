# ToDo List API

## Описание проекта

REST API для управления списком задач с использованием
матрицы Эйзенхауэра.

Проект разработан в рамках практической работы по изучению
фреймворка FastAPI.

## Функциональные возможности

- Получение информации о приложении.
- Получение списка всех задач.
- Получение задачи по ID.
- Фильтрация задач по квадрантам.
- Фильтрация задач по статусу выполнения.
- Поиск задач по ключевому слову.
- Подсчет статистики по задачам.
- Обработка некорректных запросов.

## Используемые технологии

## Установка и запуск проекта

Клонирование репозитория:

```bash
git clone https://github.com/SurdisMan/ToDo-API-BSBO.git
cd ToDo-API-BSBO
```

Создание виртуального окружения:

```bash
python3 -m venv venv
```

Активация виртуального окружения на macOS/Linux:

```bash
source venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск приложения:

```bash
uvicorn main:app --reload
```

## Endpoints

| Метод | Endpoint                   | Описание                 |
| ----- | -------------------------- | ------------------------ |
| GET   | /                          | Информация об API        |
| GET   | /tasks                     | Список всех задач        |
| GET   | /tasks/quadrant/{quadrant} | Фильтрация по квадрантам |
| GET   | /tasks/stats               | Статистика по задачам    |
| GET   | /tasks/status/{status}     | Фильтрация по статусу    |
| GET   | /tasks/search?q=проект     | Поиск задач              |
| GET   | /tasks/{task_id}           | Получение задачи по ID   |

## Документация API
